<p>The Micronaut Foundation is excited to announce the release of Micronaut framework 4.10.10! It contains releases of <a href="https://github.com/micronaut-projects/micronaut-core/releases/tag/v4.10.18">Micronaut Core</a>, and <a href="https://github.com/micronaut-projects/micronaut-test/releases/tag/v4.10.3">Micronaut Test.</a></p>
<h2>Potential denial of service attacks fixes</h2>
<p>Today, we published two security advisories that are fixed in Micronaut Core 4.10.10. Thus, strongly recommend that every user update to the latest version of Micronaut.</p>
<ul>
<li><a href="https://github.com/micronaut-projects/micronaut-core/security/advisories/GHSA-43w5-mmxv-cpvh">DoS via crafted form-urlencoded body binding with descending array indices</a></li>
<li><a class="Link--primary v-align-middle no-underline h4" href="https://github.com/micronaut-projects/micronaut-core/security/advisories/GHSA-2hcp-gjrf-7fhc">Denial of Service in HTML error response caching</a></li>
</ul>
<h2>NEXT STEPS</h2>
<p>If you haven’t yet updated to <a href="https://micronaut.io/2023/07/14/micronaut-framework-4-0-0-released/">Micronaut framework 4</a>, this is an excellent opportunity to do so!</p>
