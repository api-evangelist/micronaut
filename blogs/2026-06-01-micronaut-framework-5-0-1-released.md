The Micronaut Foundation is excited to announce the release of Micronaut framework 5.0.1! It includes releases of Micronaut Core, Micronaut Data, Micronaut GraphQL, and Micronaut JSON Schema. This release contains fixes for both GHSA-387m-935m-c4vw and GHSA-q6gh-6v2r-hjv3 security advisories.
