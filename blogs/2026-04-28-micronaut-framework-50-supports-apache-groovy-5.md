<p>Micronaut Framework 5.0, to be released in Q2 2026, supports <a href="https://groovy-lang.org/releasenotes/groovy-5.0.html">Apache Groovy 5</a>. Apache Groovy 5.0 adds new features such as:</p>
<ul>
<li>Broader JDK Support</li>
<li>Substantial Extension Method Expansion</li>
<li>Enhanced AST Transforms</li>
<li>Revamped REPL (groovysh)</li>
<li>Improved Java Interoperability</li>
<li>Modern Web Standards</li>
<li>Type Checking Enhancements</li>
<li>Additional Language Goodies</li>
</ul>
