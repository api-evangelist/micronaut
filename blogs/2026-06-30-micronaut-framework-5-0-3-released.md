The Micronaut Foundation is excited to announce the release of Micronaut framework 5.0.3! It includes releases of Micronaut Core, Micronaut AWS, Micronaut Data, Micronaut SQL, Micronaut R2DBC, Micronaut Problem, Micronaut Test, and Micronaut Micrometer. If you haven’t yet updated to Micronaut Framework 5, this is an excellent opportunity to do so!
